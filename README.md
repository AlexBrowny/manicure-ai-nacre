# Nacré — сайт, Telegram-бот и админ-панель для студии маникюра

Один Node.js-сервер, одна база (SQLite), без сборки фронтенда.

- **Сайт** (`/`) — editorial-лендинг (hero в стиле вашего примера), прайс, мастера и интерактивный календарь записи: услуга → мастер → день → время → контакты.
- **Telegram-бот** — та же запись внутри Telegram (календарь кнопками), «Мои записи» с отменой, напоминания за 2 часа и за 10 минут до визита (`REMINDER_MINUTES`), уведомления администраторам.
- **Админ-панель** (`/admin/`) — загрузка студии и мастеров, расписание по колонкам мастеров, список записей, добавление мастеров с рабочими днями/часами/перерывами/отпусками, управление услугами.

Сайт и бот пишут в одну базу и используют один и тот же расчёт свободного времени, поэтому записаться на занятое время нельзя ни там, ни там.

## Быстрый старт

Нужен Node.js 22.13+ (проверено на 24).

```bash
npm install
cp .env.example .env     # затем откройте .env и задайте ADMIN_PASSWORD и SESSION_SECRET
npm start
```

> **Windows PowerShell:** если `npm start` выдаёт «выполнение сценариев отключено в этой системе», запускайте `npm.cmd start` (и `npm.cmd install`) — или один раз разрешите скрипты для своего пользователя: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

- Сайт: <http://localhost:3000/>
- Админка: <http://localhost:3000/admin/> (пароль — `ADMIN_PASSWORD`; если не задан, при каждом запуске печатается временный)

При первом запуске в пустую базу добавляются примерные услуги и три мастера — их можно сразу править в админке.

Посмотреть админку «с жизнью»: `npm run demo` добавит ~160 демо-записей за две недели назад и неделю вперёд. Перед запуском в работу: `npm run demo:clear` (удаляет только демо-записи).

## Telegram-бот

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Впишите токен в `.env`: `TELEGRAM_BOT_TOKEN=...` и перезапустите сервер. Имя бота определится само.
3. Чтобы получать уведомления о записях, напишите своему боту `/id`, скопируйте число в `ADMIN_CHAT_IDS=` (можно несколько через запятую, можно id группы — добавьте бота в группу и отправьте там `/id`).

Запись с сайта можно «привязать» к Telegram: после записи на сайте клиент нажимает «Напоминания в Telegram» — бот напомнит о визите и позволит отменить запись.

Бот работает через long polling: запускайте **один** экземпляр сервера на один токен.

## Мини-приложение в Telegram

Страница `/app/` — тот же календарь записи, что на сайте, но открывается прямо в Telegram: кнопка «Записаться» слева от поля ввода и «📅 Календарь записи» в меню бота. Имя берётся из Telegram, телефон — из прошлых записей; запись сразу привязана к чату (напоминания и «Мои записи» работают). После записи — анимация: флакон «красит» ноготь и летит конфетти.

Сервер проверяет подпись данных Telegram (`initData`), поэтому подделать клиента нельзя.

**Как включить.** Telegram открывает мини-приложения только по **https**, localhost не подойдёт:
1. Выложите проект на сервер с HTTPS (или для пробы пробросьте порт 3000 туннелем — Cloudflare Tunnel, ngrok).
2. Впишите в `.env`: `WEBAPP_URL=https://ваш-домен/app/` и перезапустите сервер — бот сам поставит кнопку меню.
3. (По желанию) в @BotFather → Bot Settings → Configure Mini App укажите тот же адрес, чтобы мини-приложение открывалось по ссылке `t.me/имя_бота/app`.

## Как считается свободное время

- Слоты лежат на сетке `SLOT_STEP_MIN` (по умолчанию 30 минут). Услуга занимает свою длительность целиком: 2-часовой гель-лак не «влезет» перед обедом мастера.
- Из смены мастера вычитаются перерыв, выходные/отпуск и уже созданные записи. Отменённые записи время освобождают.
- «Любой мастер» — выбирается свободный мастер с наименьшей загрузкой в этот день.
- Запись закрывается за `BOOKING_LEAD_MIN` минут до начала и открыта на `BOOKING_HORIZON_DAYS` дней вперёд.
- Создание записи — атомарная транзакция: два клиента одновременно не займут один слот.
- Клиент сам может отменить запись в боте не позже чем за `CANCEL_MIN_HOURS` часов.
- Напоминания в Telegram приходят автоматически за 2 часа и за 10 минут до визита (меняется в `REMINDER_MINUTES`). Если запись сделана позже, чем «за 2 часа», придёт только «за 10 минут». В карточке записи в админке есть кнопка «🔔 Напомнить в Telegram» — отправляет напоминание сразу (не чаще раза в минуту).

## Настройки (`.env`)

Полный список с комментариями — в [.env.example](.env.example). Самое важное:

| Переменная | Зачем |
|---|---|
| `ADMIN_PASSWORD`, `SESSION_SECRET` | вход в админку; секрет подписывает сессии |
| `STUDIO_TZ` | часовой пояс студии (по умолчанию `Asia/Tashkent`) |
| `CURRENCY` | валюта в ценах (по умолчанию `сум`) |
| `STUDIO_NAME`, `STUDIO_ADDRESS`, `STUDIO_PHONE`, `STUDIO_HOURS` | показываются на сайте и в боте |
| `TELEGRAM_BOT_TOKEN`, `ADMIN_CHAT_IDS` | бот и уведомления |

## Свои фото на сайте

**Фон hero — видео с YouTube.** При каждой загрузке страницы выбирается случайный ролик о маникюре из списка в `public/js/hero-playlist.js` (не тот, что был в прошлый раз), случайный 75-секундный отрезок без заставки и титров. Видео идёт без звука, по кругу, под затемнением; пока оно грузится, показывается прелоадер с «красящимися ногтями» (`public/css/preloader.css`). Если YouTube заблокирован, ролик удалён или встраивание закрыто, плеер пробует другой, а затем остаётся запасное фото (`.hero__photo`). При включённом «уменьшении движения» в системе видео не запускается.

Чтобы добавить или заменить ролик, впишите в `HERO_VIDEOS` его id (часть ссылки после `v=`) и длину в секундах. Ролики в списке чужие: для настоящего сайта студии лучше использовать собственные съёмки (их можно загрузить на YouTube и вписать сюда) и убедиться, что у вас есть право показывать чужие видео.

Запасное фото hero (из вашего примера) и фото в рамке (бесплатный снимок с [Pexels](https://www.pexels.com/photo/crop-woman-holding-lush-lilac-twig-4376221/), автор Ioana Motoc, лицензия Pexels разрешает использование без указания автора) подгружаются с чужих серверов — перед запуском замените их своими (положите в `public/media/` и поменяйте `src` в `index.html`; приближение в рамке — `.polaroid__photo img` в `hero.css`). Для мастеров в админке есть поле «Фото (ссылка)»; без фото показывается буква на цветном фоне.

## Выкладка на сервер

- Поставьте перед приложением nginx/Caddy с HTTPS и задайте `COOKIE_SECURE=1`, `TRUST_PROXY=1` (иначе лимиты запросов будут считать все визиты как один IP).
- Резервная копия — файл `data/studio.db` (рядом могут быть `-wal`/`-shm`; копируйте при остановленном сервере или через `sqlite3 .backup`).
- Админская сессия — подписанная cookie на `ADMIN_SESSION_HOURS` часов. «Выйти» удаляет cookie в браузере; чтобы отозвать все сессии, смените `SESSION_SECRET`.

## Перед запуском в работу

- [ ] В `.env` вписать настоящие адрес, телефон, часы работы и Instagram студии; задать свой `ADMIN_PASSWORD`.
- [ ] В админке заменить примерных мастеров и цены на настоящие (разделы «Мастера» и «Услуги»).
- [ ] `npm run demo:clear` — удалить демо-записи; проверить и при необходимости отменить тестовые записи в разделе «Записи».
- [ ] Заменить чужие фото и видео своими (см. «Свои фото на сайте»).
- [ ] Выложить на сервер с HTTPS (см. «Выкладка на сервер»), сделать резервную копию `data/studio.db`.
- [ ] Пройти запись в боте из настоящего Telegram: меню → запись → отмена → напоминание.

## Структура

```
src/
  server.js          точка входа
  config.js, db.js   настройки из .env; SQLite и миграции
  time.js            даты/время в часовом поясе студии
  domain/            бизнес-логика: slots, availability, bookings, catalog, stats
  http/              Express: публичное API, админ-API, сессии, лимиты, схемы (zod)
  bot/               Telegram (grammY): сценарий записи, клавиатуры, напоминания
public/              сайт (index.html, css/, js/) и админка (admin/)
test/                node:test
scripts/seed-demo.js демо-данные
```
